W czym pomóc?

Odpowiedzi na pytania, które pojawiają się przy instalacji Shrimp i w pierwszych dniach z nim.

Przed instalacją

  • Pobieranie ShrimpShrimp Install sam pobiera i sprawdza system. Nie musisz szukać pliku ISO.
  • NośnikJaki pendrive, karta SD albo dysk zewnętrzny nadaje się dla Shrimp i co stanie się z plikami, które są na nim teraz.
  • Kopia plików z WindowsJak Shrimp Install przenosi dokumenty, zdjęcia i inne pliki z Windows do Shrimp i gdzie je potem znaleźć.
  • BitLockerGdy dysk z Windows jest zaszyfrowany funkcją BitLocker, Shrimp zainstalujesz zamiast Windows albo po wyłączeniu szyfrowania.
  • Brak internetuCo zrobić, gdy Shrimp Install albo Setup nie mogą połączyć się z internetem.
  • Uruchamianie z nośnikaJak komputer uruchamia się z nośnika Shrimp i co zrobić, gdy znowu startuje Windows.

Po instalacji

  • Sterownik NVIDIAKtóry sterownik karty NVIDIA wybrać w Setup i co zrobić, gdy po jego instalacji ekran pozostaje czarny.
  • Shrimp AppsJak instalować, aktualizować i usuwać programy w Shrimp oraz skąd wziąć odpowiedniki programów z Windows.
  • PankoJak w Panko cofnąć zmiany w systemie: przywrócić pojedyncze pliki albo cały system z migawki.
