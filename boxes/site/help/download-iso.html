Pobieranie Shrimp

Shrimp Install sam pobiera system i sprawdza, czy dotarł cały. Nie musisz szukać ani zapisywać pliku ISO.

Co dzieje się po kliknięciu „Przygotuj nośnik”

Shrimp Install pobiera najnowszą wersję Shrimp (około 2 GB), a potem sprawdza jej sumę kontrolną SHA-256. Obraz uszkodzony albo niepełny nie trafi na nośnik. Postęp, prędkość i pozostały czas widać na ekranie Przygotowanie Shrimp.

Jeśli przerwiesz przygotowanie, gdy obraz był już pobrany w całości, przy następnej próbie Shrimp Install najpierw sprawdzi ten plik i nie będzie pobierał go od nowa.

Gdy pobieranie się nie udaje

  • Brak połączenia z internetem albo Nie można połączyć się z serwerem pobierania: zobacz Brak internetu.
  • Serwer pobierania odpowiedział kodem…: kłopot jest po naszej stronie. Spróbuj ponownie za kilka minut.
  • Pobrany obraz jest uszkodzony: kliknij Spróbuj ponownie. Gdy błąd wraca, wyłącz na chwilę VPN albo spróbuj innej sieci.
  • Za mało miejsca na dysku: obraz zapisuje się tymczasowo na dysku z Windows. Zwolnij co najmniej 3 GB i spróbuj ponownie.

Czy mogę zainstalować Shrimp z samego pliku ISO?

Nie. Obraz Shrimp jest przygotowany do pracy z Shrimp Install. To Shrimp Install zapisuje nośnik, kopiuje Twoje pliki i zapamiętuje ustawienia Windows (język, strefę czasową, klawiaturę i listę programów), z których korzysta potem Setup.

Downloading Shrimp

Shrimp Install downloads the system and checks that all of it arrived. You don't need to find or save an ISO file.

What happens after you click “Prepare the drive”

Shrimp Install downloads the latest version of Shrimp (about 2 GB) and then checks its SHA-256 checksum. A damaged or incomplete image never reaches the drive. Progress, speed and the time left are shown on the Preparing Shrimp screen.

If you cancel after the image has fully downloaded, Shrimp Install checks that file on the next try instead of downloading it again.

When the download fails

  • No internet connection or Can't connect to the download server: see No internet.
  • The download server responded with code…: the problem is on our side. Try again in a few minutes.
  • The downloaded image is damaged: click Try again. If it keeps happening, turn off your VPN for a moment or try another network.
  • Not enough disk space: the image is stored temporarily on the Windows drive. Free up at least 3 GB and try again.

Can I install Shrimp from the ISO file alone?

No. The Shrimp image is made to work with Shrimp Install. Shrimp Install writes the drive, copies your files and remembers your Windows settings (language, time zone, keyboard and the list of programs), which Setup uses later.
