BitLocker

Gdy dysk z Windows jest zaszyfrowany funkcją BitLocker, Shrimp można zainstalować tylko zamiast Windows. Aby zostawić Windows, najpierw wyłącz szyfrowanie.

Dlaczego

Żeby zrobić miejsce na Shrimp obok Windows, Setup zmniejsza partycję Windows. Partycji zaszyfrowanej funkcją BitLocker nie da się bezpiecznie zmniejszyć spoza Windows. Shrimp Install pokazuje ostrzeżenie już na pierwszym ekranie, a Setup wyłącza wtedy wybór Obok Windows.

Możliwość 1: zamiast Windows

Windows zostanie usunięty, a pliki skopiowane przez Shrimp Install trafią do nowego systemu. Sprawdź wcześniej, czy kopia obejmuje wszystko, czego potrzebujesz (zobacz Kopia plików z Windows).

Możliwość 2: wyłącz szyfrowanie i zostaw Windows

  1. W Windows otwórz Ustawienia → Prywatność i zabezpieczenia → Szyfrowanie urządzenia (Windows 10: Aktualizacja i zabezpieczenia → Szyfrowanie urządzenia) i wyłącz szyfrowanie.
  2. Jeśli nie ma tam tej opcji, otwórz Panel sterowania → System i zabezpieczenia → Szyfrowanie dysków funkcją BitLocker i kliknij Wyłącz funkcję BitLocker.
  3. Poczekaj, aż odszyfrowanie się skończy. Może potrwać od kilkunastu minut do kilku godzin. W tym czasie możesz normalnie korzystać z komputera.
  4. Uruchom Shrimp Install jeszcze raz. Ostrzeżenie o BitLockerze zniknie.

Klucz odzyskiwania

Jeśli Windows zostaje na komputerze, zapisz klucz odzyskiwania BitLocker, zanim zaczniesz. Zmiana sposobu uruchamiania może sprawić, że Windows raz o niego poprosi. Klucz znajdziesz na swoim koncie Microsoft pod adresem aka.ms/myrecoverykey.

BitLocker

If the Windows drive is encrypted with BitLocker, Shrimp can only be installed instead of Windows. To keep Windows, turn encryption off first.

Why

To make room for Shrimp next to Windows, Setup shrinks the Windows partition. A partition encrypted with BitLocker can't be shrunk safely from outside Windows. Shrimp Install warns you on its first screen, and Setup then turns off the Next to Windows choice.

Option 1: instead of Windows

Windows will be removed, and the files Shrimp Install copied go to the new system. Check first that the copy includes everything you need (see Copying your files from Windows).

Option 2: turn off encryption and keep Windows

  1. In Windows, open Settings → Privacy & security → Device encryption (Windows 10: Update & Security → Device encryption) and turn encryption off.
  2. If that option isn't there, open Control Panel → System and Security → BitLocker Drive Encryption and click Turn off BitLocker.
  3. Wait until decryption finishes. It can take from a few minutes to a few hours. You can keep using the computer meanwhile.
  4. Run Shrimp Install again. The BitLocker warning will be gone.

Recovery key

If Windows stays on the computer, save your BitLocker recovery key before you start. Changing how the computer starts can make Windows ask for it once. You'll find the key in your Microsoft account at aka.ms/myrecoverykey.
