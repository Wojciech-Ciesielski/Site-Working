Uruchamianie z nośnika

Zwykle nie musisz nic robić. Po kliknięciu Uruchom ponownie w Shrimp Install komputer sam wystartuje z nośnika, a Setup poprowadzi instalację.

Jak to działa

Shrimp Install ustawia jednorazowy start z nośnika i wyłącza szybkie uruchamianie Windows, które mogłoby to zablokować. Nie trzeba wchodzić do ustawień BIOS ani UEFI. Kolejne uruchomienia wyglądają jak zwykle.

Przed ponownym uruchomieniem zapisz otwarte dokumenty. Nie odłączaj nośnika.

Komputer znowu uruchomił Windows

Sposób 1, z Windows. Przytrzymaj klawisz Shift i kliknij Start → Zasilanie → Uruchom ponownie. Na niebieskim ekranie wybierz Użyj urządzenia, a potem swój nośnik.

Sposób 2, menu startowe. Włącz komputer i od razu kilka razy naciśnij klawisz menu startowego, potem wybierz nośnik z listy. Najczęściej to:

  • F12: Dell, Lenovo, Acer i wiele innych,
  • Esc: laptopy ASUS,
  • F9: HP (czasem najpierw Esc),
  • F11: MSI, F8: płyty główne ASUS.

Komunikaty w Shrimp Install

  • Ten komputer nie uruchamia się w trybie UEFI albo Firmware nie przyjął wpisu uruchamiania: start z nośnika trzeba wybrać ręcznie, jednym ze sposobów powyżej.
  • Nie udało się uruchomić ponownie: uruchom komputer ponownie z menu Start.

Secure Boot

Zwykle nie trzeba go wyłączać. Jeśli komputer odmawia startu z nośnika z komunikatem o naruszeniu zabezpieczeń (Secure Boot violation), otwórz ustawienia UEFI i włącz opcję zezwalającą na certyfikaty firm trzecich (zwykle Allow Microsoft 3rd Party UEFI CA). Część nowych laptopów ma ją domyślnie wyłączoną.

Starting from the drive

Usually you don't need to do anything. After you click Restart in Shrimp Install, the computer starts from the drive by itself and Setup guides you through the installation.

How it works

Shrimp Install sets a one-time start from the drive and turns off Windows fast startup, which could get in the way. There's no need to open the BIOS or UEFI settings. Later starts work as usual.

Save your open documents before restarting. Keep the drive plugged in.

The computer started Windows again

Way 1, from Windows. Hold Shift and click Start → Power → Restart. On the blue screen, choose Use a device, then your drive.

Way 2, the boot menu. Turn the computer on and press the boot menu key a few times right away, then pick the drive from the list. Most often it's:

  • F12: Dell, Lenovo, Acer and many others,
  • Esc: ASUS laptops,
  • F9: HP (sometimes after Esc),
  • F11: MSI, F8: ASUS motherboards.

Messages in Shrimp Install

  • This computer doesn't start in UEFI mode or The firmware didn't accept the boot entry: choose to start from the drive by hand, using one of the ways above.
  • Couldn't restart: restart the computer from the Start menu.

Secure Boot

Usually you don't need to turn it off. If the computer refuses to start from the drive with a Secure Boot violation message, open the UEFI settings and turn on the option that allows third-party certificates (usually Allow Microsoft 3rd Party UEFI CA). Some new laptops ship with it turned off.
